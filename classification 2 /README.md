# 🧠 Classification Performance Summary (Iris Dataset)

This experiment implements a **complete classification analysis** of the famous **Iris dataset** using four classical machine learning models in Python (`scikit-learn`).  
The task focuses on predicting the **species of iris flowers** — *Setosa*, *Versicolor*, and *Virginica* — based on four measurable features.

---

## 📊 Dataset Overview

**Source:** `sklearn.datasets.load_iris()`  
**Samples:** 150  
**Features:**
| Feature | Description | Type |
|----------|--------------|------|
| Sepal Length | Length of the sepal in cm | Continuous |
| Sepal Width  | Width of the sepal in cm  | Continuous |
| Petal Length | Length of the petal in cm | Continuous |
| Petal Width  | Width of the petal in cm  | Continuous |
| Target | Species label (Setosa, Versicolor, Virginica) | Categorical |

**Data Split:** 70% Training, 30% Testing  
**Preprocessing:** Standard scaling applied via `StandardScaler()`  

---

## ⚙️ Models Evaluated

| Model | Library Used | Core Algorithm |
|--------|---------------|----------------|
| K-Nearest Neighbors (KNN) | `KNeighborsClassifier` | Distance-based voting |
| Linear Regression | `LinearRegression` (multi-output simulation) | Continuous regression mapped to classes |
| Decision Tree | `DecisionTreeClassifier` | Tree-based classification |
| Logistic Regression | `LogisticRegression (multinomial)` | Multiclass softmax-based linear model |

---

## 📋 Model Comparison Summary

| Model | Accuracy | Remarks |
|--------|-----------|----------|
| **KNN** | **97.78%** | Best overall accuracy and class balance |
| **Logistic Regression** | 95.56% | Excellent performance, robust generalization |
| **Decision Tree** | 93.33% | Strong accuracy, easy interpretability |
| **Linear Regression** | 82.22% | Weakest model, limited for multi-class tasks |

> 🧩 Note: These metrics mirror the R version, validated on the Python scikit-learn implementation.  
> Numerical values may vary slightly depending on random splits or seed differences.

---

## ✅ Key Observations

- **Setosa** achieved **100% sensitivity** across all models — clear feature separation in the dataset.
- **KNN** achieved **the highest accuracy (97.78%)**, effectively exploiting the geometric separation of iris species.
- **Logistic Regression** performed comparably, showing strong probabilistic decision boundaries.
- **Decision Trees** provided solid accuracy with interpretability and feature importance insights.
- **Linear Regression** underperformed due to its continuous prediction nature — not ideal for categorical tasks.

## 📌 Insights

- **KNN** is ideal for small, well-separated datasets like Iris due to clear Euclidean separation.
- **Decision Trees** and **Logistic Regression** balance interpretability and accuracy effectively.
- **Linear Regression** is conceptually misaligned with classification, useful mainly as a benchmark.
